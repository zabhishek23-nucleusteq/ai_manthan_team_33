Severity: SEV3 (OWASP A05 security misconfiguration). Steps: curl -I http://localhost:3000/. Expected: X-Content-Type-Options nosniff, X-Frame-Options DENY (or CSP frame-ancestors none), Referrer-Policy, and a Content-Security-Policy. Actual: only Server: nginx/1.29.8 (the API sends nosniff and X-Frame-Options, the SPA does not). Fix: add add_header lines in frontend/nginx.conf (always flag), server_tokens off. Ant Design needs style-src unsafe-inline, so start with default-src self plus connect-src self. Evidence: docs/testing/security-checklist.md.
