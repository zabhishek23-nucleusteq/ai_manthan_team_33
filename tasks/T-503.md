Since #30 the e2e-api CI job fails on main: EMPLOYEE calling POST /api/admin/users and PUT /api/admin/users/{id}/roles gets 400 (body validation runs during argument resolution, before @PreAuthorize). Non-admins must get 403 FORBIDDEN without the request being validated. Suggested fix: in SecurityConfig add .requestMatchers('/api/admin/**').hasRole('SUPER_ADMIN') before anyRequest(). This blocks merges: CLAUDE.md says merge only on green CI.
