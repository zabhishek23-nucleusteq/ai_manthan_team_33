Steps:
1. Log in as employee@expenseflow.test, open /claims (or let the session expire there)
2. Session expiry/401 sends you to /login?next=/claims&expired=1
3. Log in as admin@expenseflow.test (SUPER_ADMIN only)
Expected:
Admin lands on /admin (own landing).
Actual:
LoginPage navigates to next=/claims; RequireRole(EMPLOYEE) shows the 403 page. Same for any role opening a URL left by another role.
Cause:
frontend/src/features/auth/LoginPage.tsx:41,48 use `next ?? landingRouteFor(roles)` without checking the new user may open `next`.
Fix:
Use next only if the logged-in user has a role allowed on that route, else landingRouteFor(roles). Keep safeNext().
