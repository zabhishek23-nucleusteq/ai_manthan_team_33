## Goal
Users sign up and log in; every /api/** protected

## Acceptance criteria
- [ ] Flyway: users (id, name, email unique, password_hash, department_id, manager_id, enabled), roles, user_roles; BCrypt
- [ ] POST /api/auth/signup creates EMPLOYEE only, 409 EMAIL_TAKEN on duplicate; POST /api/auth/login -> {accessToken, tokenType, expiresIn, user{id,name,email,roles}}; GET /api/auth/me
- [ ] Stateless HS256 JWT (sub, roles, exp 8h, secret from env); 401 {code:UNAUTHENTICATED}, 403 {code:FORBIDDEN} JSON
- [ ] Roles EMPLOYEE, MANAGER, FINANCE_AUDITOR, FINANCE_HEAD, SUPER_ADMIN per docs/architecture/rbac.md

## Tests required
- login ok
- wrong password 401
- signup 201
- duplicate email 409
- no token 401
- wrong role 403
