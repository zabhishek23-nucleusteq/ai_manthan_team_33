**Correction:** The first `start.ps1` aborted on a healthy run: Claude had set `$ErrorActionPreference = 'Stop'`, and in Windows PowerShell 5.1 docker's progress output on **stderr** is treated as a terminating error. Re-verified: all 4 containers up, backend health UP, frontend 200, mock-bank UP.
**Outcome:** one-command start used by every laptop; unblocked T-009 CI and the S1 gate.
